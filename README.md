## 这是什么

给老板（你）造的**多智能体协作工作站**：产品经理、UI、架构师、前端、后端、测试、文职七人团队常驻待命。你在群聊里 @ 一个名字派活，它就干活——能读写文件、执行命令，但**每一项危险操作都必须经你逐个审批**。手机装个 App 就是随身遥控器，出门也能指挥家里的电脑。

它不是又一个聊天套壳。它解决的是**多智能体协作的失控问题**。

## 解决了什么问题

| 痛点 | ErgoAgent 的答案 |
|---|---|
| 多个 AI 各自为战，产出对不上 | **串行执行门**（一次一个任务不交错）+ 立项《项目方案》锚定方向 + **整合验收**（冲突扫描→合并产物→不兼容清单） |
| AI 乱写文件、乱跑命令 | **逐项审批门**：写文件/执行命令必须你点“允许”；命令黑名单硬拦截（bcdedit/diskpart/format 等）；路径沙箱防逃逸 |
| 多端同时在线互相抢消息 | 全局事件广播 + **双端审批同步**——手机批的电脑同步看到，不会重复审批 |
| 并行开发不兼容 | 方案里的**接口契约**（模块边界/签名/数据格式）+ 任务完成后的**同名冲突扫描** |
| 上手门槛高 | **手机连接码**一键配对（复制一行、粘贴即连）；启动引导分步提示 |
| 数据隐私 | 聊天记录、文件、令牌**全在你电脑上**，卸载即删，无云端 |

## 一张图看懂：老板模式工作流

```mermaid
flowchart TD
    A[👤 老板下达工作单] --> B{选了讨论组?}
    B -- 是 --> C[💬 开题讨论: 小群先议]
    C --> D[📋 《项目方案》<br/>目标/路径/分工/风险/<b>接口契约</b>]
    B -- 否 --> E[🧭 调度智能体直接拆解]
    D --> F[⚖️ 老板审批方案]
    F -- 打回重议 --> C
    F -- 通过 --> G[🧩 拆解任务卡]
    E --> G
    G --> H[🚀 分发执行<br/>串行门: 一次一个任务不交错]
    H --> I[📦 交付物 · 审核组把关]
    I --> J{全部任务完成?}
    J -- 否 --> H
    J -- 是 --> K[🔧 整合验收 (自动生成卡)<br/>冲突扫描 → 合并进 project/ → 接口契约核对 → 不兼容清单]
    K --> L[📝 结项讨论 →《结项结论》]
    L --> M[⚖️ 终审 · 老板确认交付]

    H -. 执行中可随时插话 .-> H
    H -. 写文件/执行命令需逐项审批 .-> I
```

**三道兼容性防线**：事前「接口契约」对齐边界 → 事中「串行门」不交错 → 事后「冲突扫描 + 整合验收」把散件拼成整体。日常聊天更简单：@ 谁谁干活，智能体的每个危险操作弹卡等你批。

## 特点

- **群聊即控制台**：@ 谁谁干活；智能体之间也能互相讨论、互相指导
- **完整“老板模式”工作单**：立项（含接口契约）→ 开题讨论 → 拆解任务卡 → 并行/串行执行 → 交付物审核 → 整合验收 → 终审 → 结项结论
- **运行中随时插话**：智能体干活时你直接打字补指示，即时注入它的上下文
- **📎 文件上传**：多选/拖拽/粘贴截图，参考文件随手给，智能体用 read_file 读取
- **私聊与会话列表**：QQ 式消息页，每个成员独立上下文的私聊，未读红点
- **双端形态**：Windows 客户端（exe 双击即用）+ Android App（apk 安装包），实时同步
- **澎湃质感界面**：主题色可换、胶囊化交互、启动动效、深浅适宜的信息密度
- **Token 预算与熔断**：单轮工具上限、预算封顶自动暂停，不会失控烧钱

## 发展历程

这个项目诞生于一个真实的不耐烦：**“为什么指挥一堆 AI 干活，比自己干还累？”**

1. **原型**——先把群聊做对：@ 谁谁干活、mock 演示档（零配置试全流程）与真实 LLM 档并存、工具沙箱与审批门从第一天就有。安全不是补丁，是地基。
2. **秩序**——多任务并行时的混乱催生了**串行执行门**与全局事件广播；手机浏览器接入后，多端抢事件的问题用“单条全局流”根治。
3. **组织**——“老板模式”工作单成型：方案锚定、开题讨论、任务卡、交付物、审核组、终审、结项结论——一支团队该有的流程，一样不少。
4. **产品化**——QQ 式会话列表与私聊、澎湃质感 UI 与主题色、开机式启动动效、**手机连接码**把配对门槛打到一行粘贴、文件上传、运行中插话。
5. **整合**——针对“各自做完怎么拼”的终极问题：**接口契约前置 + 冲突扫描 + 自动整合验收卡**，不兼容清单直接呈到终审面前。
6. **质量**——**159 项自动化测试**常绿：97 项功能回归 + 20 项全栈模拟（含模拟手机远程连接）+ 42 项对抗性安全探针。

## 快速开始（Windows）

1. 下载 `ErgoAgent.exe`，双击——就这一步。启动引导窗口里有手机连接码。
2. **手机**：下载 `ErgoAgent-debug.apk` 安装 → 侧栏「服务器设置」→ 粘贴电脑窗口里的**手机连接码** → 完成。
3. 不装 App 也行：手机浏览器打开引导窗口里打印的地址，输入令牌。

**系统要求**：Windows 10/11（客户端）；Android 8+（手机 App）；电脑需开机在线（它是引擎）。

## 安全说明

- 所有数据接口需**访问令牌**；写文件/执行命令需**逐项审批**；高危命令黑名单硬拦截。
- 局域网模式下同网设备需凭令牌访问；**公共 WiFi 请勿开启手机连接**（`ErgoAgent.exe --local` 仅本机模式）。
- 传输为局域网明文 HTTP，令牌防的是陌生设备误入，不防同网专业嗅探——家庭/个人网络场景风险可控。
